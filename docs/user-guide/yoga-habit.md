# How does the Yoga Habit page work?

## The page

Visit [https://go.tiffanywoodyoga.com](https://go.tiffanywoodyoga.com) to see the public landing page for the monthly free class.

## The Instagram, Facebook, and YouTube links

This same page also opens at three shorter addresses, one for each place a link lives:

- **Instagram bio**: [https://go.tiffanywoodyoga.com/ig](https://go.tiffanywoodyoga.com/ig)
- **Facebook Page**: [https://go.tiffanywoodyoga.com/fb](https://go.tiffanywoodyoga.com/fb)
- **YouTube channel description**: [https://go.tiffanywoodyoga.com/yt](https://go.tiffanywoodyoga.com/yt)

All three open the exact same page: same class date, same registration button, nothing different by platform. There is no separate content, offer, or price for any of the three, and registering looks and works identically no matter which address a visitor used. The only difference is invisible to the visitor: each address tags where they came from, so the stats above can show Instagram, Facebook, and YouTube separately.

There is nothing to turn on or off here. All three addresses are always live.

## What visitors see

- The next Yoga Habit class date and time.
- A registration button that links to the HeyMarvelous event.
- If the visitor came from the newsletter, the page adjusts what it shows (lifestyle members see different CTAs than non-members).

## After the class

The system automatically sends follow-up emails to attendees:

- A thank-you with a discount coupon code.
- The coupon is unique per month (format: HABIT_MONYYYY, e.g., HABIT_APR2026).
- Redemptions are tracked automatically.

## Stats and analytics

You can see how the Habit page is performing at any time:

[https://habit.tiffanywoodyoga.com/stats?key=z0OvK27qdQ3BtZBc8D_6og](https://habit.tiffanywoodyoga.com/stats?key=z0OvK27qdQ3BtZBc8D_6og)

This shows registration trends, where visitors come from, and which buttons are getting clicks.

## What you need to do

Nothing for the page itself. It updates automatically based on the next scheduled Habit event.

The [go.tiffanywoodyoga.com](https://go.tiffanywoodyoga.com) URL also points here. This is what the logo in the marketing emails links to.
