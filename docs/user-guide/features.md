# How does Features? work?

**Features?** lists things that could be built for the studio. It is at [classes.tiffanywoodyoga.com/features](https://classes.tiffanywoodyoga.com/features), and the Features? button at the foot of the column on the right edge of the Classes calendar opens it.

Every item says the same four things, so two of them can be compared at a glance:

- **Title**, what it is called.
- **Description**, what it does.
- **Benefit**, what it changes for the studio.
- **Cost**, what it would come to.

## Pending

Open an item and there are two buttons:

- **Yes**: it gets built, and word comes back when it is running.
- **Not now**: it moves down to **Later** and stays there.

There is no No. Anything under Later can be said yes to at any time, and an answer already given can be changed.

## Approved and Completed

An item said yes to moves to **Approved** and waits there while it is built. Once it is running it moves again, to **Completed**, with the date. A completed item is a record rather than a question, so it has no buttons and it sits greyed at the foot of the page.

## The In use label

Some items are already running and have been for months, built as part of the work rather than paid for separately. Those carry an **In use** label and sit below the rest, because the question on them is not whether to start but whether to keep them going. A note on each one says so.

## Notes

Every item has a notes box, reachable from the list or from the item itself. A note is saved exactly as written and stays that way, so nobody can quietly reword what was said. To add to it, or say something different later, write another note.

## Asking for something

**Ask**, in the top right, takes a request in plain words. That item then sits at the top of the page waiting on a cost, and comes back with the same four things and the same two buttons as everything else.

## What it will not do

- Saying yes is not a bill. It is the go-ahead to build, and the work is invoiced the way it always is.
- A cost is an estimate. If something looks like it will go past it, word comes first, before the work does.
- Nothing on this page sends an email, changes a class or touches the website. It is a list of decisions, not a set of switches.
- Items set aside are never cleaned out.
