# What are the placeholder classes on the calendar?

Every day an automatic job keeps the studio calendar filled 60 days ahead with placeholder classes:

- Monday 5:30pm: Stretch or Strength, alternating weekly.
- Tuesday 8:00am: Principles or Flow, alternating weekly.
- Thursday 8:00am: Expansion.
- The last Saturday of each month, 9:00am: Integration.

The monthly Yoga Habit class is created separately and is not part of this.

## What a placeholder is

A generic event named for its class type, with a standard description. It becomes a real class when that day's class plan is published to it. The job never edits or renames an existing event, and it never touches a class that a published plan points at.

## Moving the monthly Integration class

The job considers a month's Integration covered when a class plan with type Integration exists anywhere in that month, even after that class date has passed. So when the Integration class moves to an earlier Saturday and the leftover last-Saturday placeholder is deleted in HeyMarvelous, the deletion sticks. Before August 29, 2026 the deleted placeholder could silently come back once the moved class had been taught. That is fixed.

## What it will NOT do

There is no way yet to mark a month as having no Integration class at all. If no Integration class plan exists anywhere in the month, the job re-creates the last-Saturday placeholder on its next run even after it was deleted. If a month should truly have no Integration class, tell JP.

## How a new placeholder is announced

Every placeholder the job creates is posted to the #status-classes Slack channel, so JP sees any class appearing on the calendar the day it appears, never discovered in class.
