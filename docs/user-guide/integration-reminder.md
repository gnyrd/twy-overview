# How does the Integration reminder work?

Two emails go to members before each month's Integration class. The class details fill themselves in from the class plan, and the wording is approved fresh each month.

## What sends, and when

| Email | When it sends | What it says |
|-------|---------------|--------------|
| Email 1 | 9:00 in the morning, two days before the class | The class name, the date, the time and the link |
| Email 2 | 7:00 in the morning on the day of the class | A short note that it is this morning |

Both go to **Audience: TYL Members**, the current Yoga Lifestyle members, which is kept current every night from HeyMarvelous. Nobody else receives them.

## Where the class details come from

The class plan. The campaign reads the month's Integration plan and fills in the title, the date, the time and the link to the class page. Change the plan and the emails change with it. There is nothing to retype each month.

## What you do

Open **Emails**, then **Integration Reminder**. Read the two emails, edit the wording for that month's class, and tick **Approved** on each.

That happens every month. An approval covers one month only, so nothing goes out until it is given again. The Wednesday before the class is enough time.

Once a month's two emails have both gone, a new approval counts for the month after, so there is no wrong moment to do it.

## What holds it

- **No Integration plan for the month.** Nothing sends. The emails wait, and they go out if you write the plan in time.
- **A plan that is still a placeholder.** Same thing: a plan counts once it has real content in it.
- **A plan not published to HeyMarvelous yet.** The emails need the class page to link to, so they wait for it rather than send a broken link.
- **An email not yet approved for this month.** Nothing sends until both are approved, and last month's approval does not carry over.

In every one of those cases the emails hold and then send late if the missing piece arrives in time. None of them sends a half finished email.

## What it will not do

- It does not register anyone. It links to the class page, where they register themselves.
- It does not replace the WhatsApp post unless you stop posting.
- It does not email non members.
